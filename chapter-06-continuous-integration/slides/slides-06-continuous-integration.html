Create a local environment

macOS / Linux:

python3.12 -m venv .venv
source .venv/bin/activate

Windows PowerShell:

py -3.12 -m venv .venv
.venv\Scripts\Activate.ps1

After activation, use python on either platform.

Run the app locally

python -m pip install -r requirements-test.txt
python main.py

Open http://localhost:8080.

Click 2, +, 3, =. Expected display: 5.

python -m pytest -v test_calculator.py

Run the simulated GUI tests

python -m pytest -v test_main.py

Create webcalc on GitHub

Use --public for a public class repository.

Alternative: create it on the website

Create an empty repository named webcalc on GitHub.

Leave README, license, and gitignore initialization unchecked.

Replace YOUR_USERNAME, then run:

git remote add origin https://github.com/YOUR_USERNAME/webcalc.git
git push -u origin main

Use this route or the CLI creation route, not both.

The workflow lives with the code

File: .github/workflows/webcalc-tests.yml

name: WebCalc tests
on:
  push:
  pull_request:
  workflow_dispatch:

Pushes start runs. The manual trigger supports reruns on demand.

Three jobs from one matrix

strategy:
  fail-fast: false
  matrix:
    layer: [unit, simulated-gui, browser]

Each layer gets its own runner and result.

A unit failure does not cancel the other two jobs.

The same commands, on another machine

Job Test command
unit python -m pytest -v test_calculator.py
simulated-gui python -m pytest -v test_main.py
browser python run_browser_tests.py

The workflow adds report options and saves artifacts.

No development server needs to be left running.

Break one expectation

File: test_calculator.py, function test_addition.

Change the final assertion to:

assert calc.display == '6'
python -m pytest -v test_calculator.py -k test_addition

Expected: 1 failed. Actual 5; deliberately expected 6.

Push the known failure

git add test_calculator.py
git commit -m "Demonstrate a failing addition check"
git push

Open the new Actions run.

unit simulated-gui browser
Fail Pass Pass

Read the failed assertion

Open WebCalc / unit > Test calculator logic.

Expected comparison:

actual display:    '5'
expected display:  '6'

The test is wrong in this exercise. Repair the expectation.

Repair it locally

Restore test_addition:

assert calc.display == '5'

Run all three layers:

python -m pytest -v test_calculator.py
python -m pytest -v test_main.py
python run_browser_tests.py

Expected: 27 tests, 12 tests, 12 scenarios pass.

Push the repair and confirm green

git add test_calculator.py
git commit -m "Restore the correct addition expectation"
git push

Expected: all three jobs pass on the new run.

The earlier failed run remains attached to the earlier commit.
