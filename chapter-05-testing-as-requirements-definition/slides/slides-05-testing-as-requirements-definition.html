Given: establish the starting state

@given("I have opened the Wikipedia home page")
def open_home_page(context):
    context.browser = webdriver.Chrome()
    context.add_cleanup(context.browser.quit)
    context.wait = WebDriverWait(context.browser, 15)
    context.browser.get(
        "https://en.wikipedia.org/wiki/Main_Page")

The saved example also waits for a usable search box.

When: perform and check the action

start = context.browser.current_url
box = context.browser.find_element(By.NAME, "search")
box.send_keys("Light Bulb", Keys.ENTER)
context.wait.until(EC.url_changes(start))
heading = context.browser.find_element(
    By.ID, "firstHeading").text
assert not heading.startswith("Search results"), heading

Why wait for a URL change?

Then: check the agreed result

@then("the page text contains Edison")
def page_text_contains_edison(context):
    text = context.browser.find_element(
        By.TAG_NAME, "body").text
    assert "Edison" in text

No extra navigation hidden inside the check.

What could leak from one scenario into another?

Failure leaves something to inspect

def after_scenario(context, scenario):
    if scenario.status == "failed":
        name = re.sub(r"\W+", "-", scenario.name)
        # The saved version also normalizes the name.
        os.makedirs("screenshots", exist_ok=True)
        context.browser.save_screenshot(
            f"screenshots/{name}.png")

A screenshot helps explain a failure. It does not decide correctness.

Scenario Outline: A numeric cell
  When I type "<entry>" into a cell
  Then the cell holds the number <number>

  Examples:
    | entry | number |
    | 007   | 7      |
    | .5    | 0.5    |
    | -12.5 | -12.5  |

The table is a small, reviewable specification.

When records what happened

@when('I type "{entry}" into a cell')
def enter_cell(context, entry):
    context.value = None
    context.error = None
    try:
        context.value = parse(entry)
    except ValueError as error:
        context.error = error

Rejection can be the expected result.

Then decides whether it was right

@then("the cell holds the number {number}")
def check_number(context, number):
    assert context.error is None
    assert math.isclose(context.value, float(number),
                        rel_tol=1e-12, abs_tol=1e-12)

@then("the cell is rejected as not a number")
def check_rejection(context):
    assert context.error is not None
