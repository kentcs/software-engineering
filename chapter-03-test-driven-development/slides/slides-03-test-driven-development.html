The development cycle

Stage Work
Red Specify one behavior; see the test fail
Green Implement it; rerun every test
Refactor Improve the code; keep tests passing

The next example requires a more general rule.

Single-digit implementation

def parse(text):
    return float(ord(text[0]) - ord("0"))

"0": 48 - 48 = 0

"9": 57 - 48 = 9

Rerun the earlier examples.

Test procedures called from main

def test_single_digits():
    check("0", 0.0)
    check("3", 3.0)
    check("7", 7.0)
    check("9", 9.0)


def main():
    test_single_digits()

A named test still needs a call.

What counts as the expected value?

math.isclose(actual, expected,
             rel_tol=1e-12, abs_tol=1e-12)

Small rounding differences may be acceptable.

A misplaced decimal point is not.

Choose the tolerance to fit the requirement.

A test for rejection

def check_rejected(text):
    try:
        parse(text)
    except ValueError:
        return
    raise AssertionError("Expected ValueError")

A normal return must fail this test.
